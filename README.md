# MyDesk — Professional UI

This ZIP is a standalone front-end redesign based on the screenshots you provided.

Included:
- Dashboard
- Tasks
- Expenses
- Attendance
- Study / Stopwatch
- Dark + Light mode
- LocalStorage persistence
- Responsive layout
- Professional blue/purple visual system
- Empty states, cards, forms, filters and tables

## Run

Open `index.html` in a browser.

For VS Code, the easiest option is Live Server.

## Important

This is a front-end replacement. It does not contain your existing Google OAuth/backend/authentication code. If your current project already has authentication or a database, keep those parts and merge the UI instead of replacing the backend.
